Gerenciador de Contatos:
1. Criação de uma classe chamada Contato que represente um contato.  
2. A classe Contato deve ter os seguintes atributos:  
      nome: nome do contato.  
      e-mail: endereço de e-mail do contato.  
      telefone: número de telefone do contato.  
 3. A classe Contato deve ter os seguintes métodos:
      __construct(): inicializarção do objeto.  
      getNome(): retorna o nome do contato.
      setNome(): insere ou atualiza o nome do contato.
      getEmail(): retorna o endereço de e-mail do contato.
      setEmail(): insere ou atualiza o email do contato.    
      getTelefone(): retorna o número de telefone do contato.
      setTelefone(): insere ou atualiza o telefone do contato.
      exibirDados(): retorna todo cadastro do contato.

    => Esse pequeno sistema é feito em PHP com POO. Ele insere/visualiza os seguintes dados (nome, email e telefone), possue um método
    Construtor para inicialização do objeto, e um método para visualizar todos os dados do contato.
    => Para rodar ele no seu pc é só copiar e colar no seu servidor, nesse caso foi utilizado o xampp na pasta htdocs e abri-lo com
    o VSCode.
